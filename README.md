# Royal Biryani Project

Create a complete, premium, highly visual, responsive frontend website for a restaurant brand called:

# **NAWAAB – The Taste of Royals**

NAWAAB is primarily known for **Biryani**.

The main identity of the restaurant should be built around this idea:

# **“Biryani is the Heart of NAWAAB.”**

NAWAAB also serves:

* Indian cuisine
* Tandoor dishes
* Indo-Chinese / Chinese cuisine

However, the visual and content priority of the website should always remain:

**Biryani first → Tandoor → Indian → Chinese**

The website must feel like a premium restaurant experience rather than a generic food website.

The overall design should be:

* Premium
* Royal
* Moody
* Warm
* Elegant
* Modern
* Cinematic
* Food-focused
* Highly visual
* Sophisticated
* Welcoming

The website should NOT look like:

* A food delivery app
* A hotel website
* A wedding website
* A traditional palace website
* An overly decorative Mughal website
* A generic restaurant template
* An AI-generated website

The final impression should be:

**“This restaurant is serious about Biryani.”**

And immediately after that:

**“This looks like a premium restaurant I would actually like to visit.”**

---

# 1. CORE VISUAL IDENTITY

The design should use a **premium dark and moody royal restaurant aesthetic**.

The website should be dark, but **not too dark**.

Do NOT use pure black everywhere.

Instead, use warm dark tones mixed with gold, ivory, cream and white.

The website should feel inspired by:

**Warm evening restaurant lighting, rich food photography, elegant gold detailing and soft ivory typography.**

## Main Color Palette

Use a controlled palette consisting of:

### Dark / Moody Colors

* Deep warm charcoal
* Espresso black
* Dark chocolate brown
* Soft black-brown
* Deep muted maroon
* Dark burgundy where appropriate

### Light Colors

* Warm ivory
* Cream white
* Soft off-white
* Warm beige
* Light neutral tones

### Accent Colors

* Antique gold
* Champagne gold
* Muted brass
* Soft metallic gold

Gold should NOT be bright yellow.

Avoid neon gold.

Avoid large blocks of shiny metallic gold.

Gold should be elegant, subtle and refined.

---

# 2. COLOR BALANCE

Use approximately:

* **55–60% dark moody tones**
* **20–25% warm ivory / cream / soft white**
* **10–15% muted gold**
* **5–10% maroon / neutral supporting accents**

The website should alternate between dark and light sections so it does not feel too heavy.

For example:

### Dark Sections

Use:

* Warm charcoal
* Espresso
* Dark maroon
* Brown-black
* Subtle dark gradients

### Light Sections

Use:

* Ivory
* Warm cream
* Off-white
* Soft beige

This alternating approach should create visual rhythm.

---

Gold should be used selectively.

Use muted gold for:

* Small divider lines
* Section labels

* Icons

**Warm Ivory / Cream White**

Gold can be used to highlight important words.

The word **Biryani** or **Heart** can have a muted gold accent.
